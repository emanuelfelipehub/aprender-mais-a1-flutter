# Aprender+ | Módulo A1

Aplicativo Android de treino baseado no projeto-teste Aprender+, da modalidade Desenvolvimento de Aplicativos Móveis. O módulo reúne jogos educativos e recursos do Android em uma interface Flutter.

## Funcionalidades

- Quiz com perguntas de múltipla escolha, verdadeiro ou falso e associação.
- Jogos de sequência de cores e memória, com pontuação.
- Integração com sensores, áudio, galeria e widget Android de pontuações.
- Conteúdo local, sem necessidade de servidor para os jogos.

## Tecnologias

Flutter, Dart, Kotlin, Android e dados em JSON.

## Executar

Instale o Flutter e configure um dispositivo Android ou emulador. Na pasta do projeto:

```bash
flutter pub get
flutter run
```

O projeto foi preparado para Android. O APK gerado não está incluído neste repositório. Para informações de implementação e limites da verificação feita durante o treino, consulte `estudo/REQUISITOS_E_TESTES.md`.

## Contexto

Exercício de preparação baseado em um projeto-teste da WorldSkills. Os recursos visuais e outros materiais fornecidos no enunciado são usados no contexto do treino.
